# Douaa — صفحة التحميل

صفحة عربية متجاوبة لتطبيق Douaa، إهداء من سالم أحمد إلى دعاء، برعاية Aite.

ملف `index.html` مستقل ويضم الصور والخطوط، ويمكن فتحه محلياً أو نشره على Cloudflare Pages كصفحة ثابتة. أزرار التحميل تشير مباشرة إلى ملف APK المستضاف على Cloudflare R2.

معاينة الهاتف في الصفحة توضيحية وليست لقطة حقيقية للتطبيق.
